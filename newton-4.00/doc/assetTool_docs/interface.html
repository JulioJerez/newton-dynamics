Interface Overview

The editor is organized into dockable panels surrounding a 3D viewport. All panels are built with ImGui and can be freely repositioned.

Layout

When you launch the editor you see four persistent areas:

┌─────────────────────────────────────────────────────────┐ │ Menu Bar File · Tools · Options │ ├──────────────────────────────────────────────────────────┤ │ Main Toolbar undo · redo · lock · camera · projection │ ├───────────────────┬──────────────────────────────────────┤ │ │ │ │ Outliner Panel │ 3D Viewport │ │ │ │ │ scene hierarchy │ (rendered scene + gizmos) │ │ │ │ ├───────────────────┴──────────────────────────────────────┤ │ Properties Panel — context-sensitive for selection │ └─────────────────────────────────────────────────────────-┘
Tip: Panels can be detached and re-docked using ImGui's docking system. Drag any panel title bar to reposition it.

Menu Bar

File

ItemDescription
NewClears the current scene and creates a blank root node. Resets undo history.
LoadOpens a .nd file. Replaces the current scene.
SaveWrites the current scene back to the existing path.
Save As…Prompts for a new path and saves. Also resets the current selection.
Import fbxImports an FBX file using name-suffix conventions to auto-create physics (see File Formats).
Import urdfImports a URDF robot description file, reconstructing links, joints, and collision shapes.
ExitCloses the editor.

Tools

Opens modal tool windows. Each tool shows a floating panel you can close with the × button or by clicking execute.

ToolWhat it does
resize meshUniformly scales all geometry and collision by a factor.
rotate meshRotates the entire mesh coordinate system by pitch/yaw/roll.
rotate pivotsRotates node pivot matrices without moving geometry.
rotate bonesRotates bones and updates their inertia tensors accordingly.
normalize mass distributionDistributes a target total mass across all bodies by volume.

Main Toolbar

A horizontal panel pinned below the menu bar. Contains quick-access buttons.

ControlDescription
undo / redoSteps backward or forward through the undo stack. See Undo/Redo.
Lock / Unlock selectionPrevents mouse-clicks in the viewport from changing the selection. Useful when editing properties.
Camera mode dropdownPreset views: free camera, back, front, left side, right side.
Perspective / OrthographicToggles the camera projection mode. Label shows the current mode; click to switch.

Outliner Panel

Displays the full scene hierarchy as a collapsible tree. Every node in the ndMesh tree appears here.

  • Click a node to select it. The Properties Panel updates immediately.
  • Collapse all button collapses the entire tree except the root, helping with large rigs.
  • Special container nodes — Loop Joints and Colliding Pairs — appear as children of the root and expand to show their contents.
  • Mesh nodes with rigid bodies show sub-items: joint, geometry, rigidBody.
Note: The currently selected node is highlighted in the Outliner. If Lock Selection is active, clicking in the outliner will still change the selection.

Properties Panel

Shows collapsible sections relevant to the selected node type.

Selection typeSections shown
Mesh node with no bodyMesh node, Render materials, Custom properties
Mesh node with rigid bodyAll of the above + Constraint joint (if joint exists) + Collision shape + Rigid body
Loop joints containerLoop joint section listing all loop constraints
Colliding pairs containerColliding Pairs section listing all excluded pairs

For full details on each section see Physics Properties.

Viewport

The central 3D view. Rendering uses multiple passes in order:

  1. Shadow pass — generates shadow maps
  2. Color pass — shaded geometry (active only in Shaded mode)
  3. Environment pass — cube-mapped background
  4. Debug display pass — gizmos, wireframes, selection highlights, collision shapes
  5. Menu pass — all ImGui panels rendered on top

Mouse interaction in the viewport fires a ray-cast to select geometry or bones depending on the Show mesh skeleton toggle.

Render Options Quick Reference

Shaded mode renders full PBR shading and environment reflections.
Wireframe mode draws only mesh edges in a neutral color.
Hidden Surface mode renders a z-buffer pass first, then overlays wireframe edges — useful for seeing topology through solid surfaces.
