Mesh Tools

Batch transform and physics utilities accessible from Tools in the menu bar. Each tool opens a floating window you can close at any time.

How Tools Work

Tools are modal operations. When you open a tool:

  • A floating ImGui window appears with the tool's parameters.
  • You configure parameters and click execute to apply.
  • Closing the window (× button) cancels without applying.
  • Every successful execute is wrapped in an undo/redo pair, so you can reverse it with Ctrl+Z equivalent (the undo button in the toolbar).
Tip: You can open the Resize Mesh tool to see bounding box dimensions of the current scene without actually applying any scale.

Resize Mesh

🔧 resize mesh

Uniformly scales all vertex positions, collision shapes, and inertia tensors by a single factor.

size (read-only)Current X/Y/Z bounding box dimensions. Useful for reference without making changes.
apply scaleThe uniform scale factor to apply. Clamped 0.01 – 100. Default 1.0 (no change).
executeApplies the scale. Only fires if scale ≠ 1.0. Resets the field to 1.0 after execution.

Under the hood, scale is applied as a diagonal 3×3 matrix transform to all mesh geometry, then collision shapes use ApplyScale and inertia tensors are adjusted to match the new dimensions. Joint frames are not currently scaled (marked for future work).

Note: Collision shape inertia scaling is partially implemented. Physics bodies marked with ndAssert(0) inside the scale path may not scale physics correctly — review bodies manually after resizing.

Rotate Mesh

🔄 rotate mesh

Rotates the entire scene's coordinate system by a given Euler rotation. Useful when imported meshes arrive with a wrong-up-axis orientation.

anglesPitch / Yaw / Roll in degrees. All three axes applied simultaneously as a combined rotation.
executeApplies the rotation. Only fires if at least one angle ≠ 0. Resets all angles to 0.0 after execution.

This calls ApplyCoordinateRotation which rotates all vertex positions and normals. Physics body transforms are not automatically updated by this tool — commented-out code exists for that and may be enabled in a future release.

Rotate Pivots

📐 rotate pivots

Rotates all node pivot matrices without moving vertex geometry. Use this to re-align joint axes after importing from a DCC tool.

anglesPitch / Yaw / Roll in degrees.
executeCalls ApplyPivotsRotation on the root mesh. Visual scene is rebuilt after execution.

Rotate Bones

🦴 rotate bones

Rotates only bone nodes and updates their inertia tensors, collision shape local matrices, and joint frames to match the new orientation.

anglesPitch / Yaw / Roll in degrees. Applied as inverse rotation to body data so the bone structure aligns correctly.
executeApplies rotation to all bone-type nodes. Non-bone nodes are untouched.

This is the preferred tool for skeletons imported with a wrong axis convention. It handles the inertia and joint frame updates that Rotate Mesh skips.

Normalize Mass Distribution

⚖️ normalize mass distribution

Distributes a target total mass across all rigid bodies proportionally to their collision volume, then optionally enforces a minimum inertia ratio so no axis is disproportionately low.

total massTarget total mass in kg for the entire model. Must be ≥ 1.0.
principal Inertia ratioMinimum ratio between smallest and largest principal inertia. Clamped 0.1 – 1.0. Lower values allow more extreme inertia distributions.
executeComputes total volume across all bodies, derives a density, then assigns per-body mass = density × volume × massVolumeWeigh. Inertia axes are then clamped to the ratio.

This tool requires each body to have a collision shape. Bodies with Null collision contribute zero volume and receive zero mass.

Tip: Use the mass weigh field on individual rigid bodies (in the Rigid Body section of Properties) to bias heavier or lighter relative to pure volume, then run this tool to normalize the total.
