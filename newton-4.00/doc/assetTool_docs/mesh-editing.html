Mesh & Body Editing

The Properties Panel changes shape depending on what's selected. For a regular mesh node it shows up to five collapsible sections, in this order.

Properties Panel

1Mesh node

Identity, visibility, structure, and the node's own transform.

Fields
Name
renamed on Enter; duplicates get a numeric suffix
Parent space transform
edits absolute values instead of relative deltas
Transform pivot only
move the pivot without dragging geometry/children
Visible
show/hide the node's render mesh

Buttons: Add node (new empty child), Clone node (duplicates the subtree with unique names), Delete node, Delete node, preserve children (re‑parents children to the removed node's parent, correcting their joints so nothing moves), and, depending on whether the node already has a body, Add body / Delete body.

Node transform & geometry transform

Two independent 3D position/rotation fields: the node's own pivot, and the local offset of its render geometry relative to that pivot. Both respect the Parent space transform toggle above — on, you edit the absolute matrix; off, each entry is a relative nudge applied on top of the current transform.

Align to target lets you pick a second node in the viewport/outliner and instantly re‑orients the selected node's X axis to point at it.

Modifier runtime behavior

Nodes without a rigid body can carry a transform modifier, evaluated at runtime:

ModifierPurpose
LookAtorients the node toward a target node
TwoLinksIKtwo‑bone IK solver; needs a child link and a solution sign
UserDefineda named hook resolved by game code at load time

2Render materials

Only shown when the node has geometry. Pick a material from the list, then edit ambient, diffuse, specular, reflection (each RGB), opacity, shininess, and the texture file name. Changes rebuild the node's visual mesh immediately.

3Custom properties

Free‑form metadata attached to a node, exported with the asset for game code to read. Three types, switchable per property:

Property types
Float
a single numeric value
String
free text
Node
a reference to another mesh node, picked via "select target node"

4Collision shape

Shown for any node that has a rigid body. Pick a shape type from the dropdown, then edit its parameters and local transform (position, rotation, scale, plus a collidable checkbox to disable collision without deleting the shape).

Shape parameters
Null
no parameters
Box
x / y / z
Sphere
radius
Capsule

Cylinder
radius0 / radius1 / height
Chamfer cylinder
radius / height
Convex hull
tolerance / max point count
Compound
read‑only sub‑shape count

Build visual mesh regenerates the node's render geometry directly from its collision shape — a quick way to get a placeholder visual while you're still blocking out physics.

5Rigid body

Mass & integration
Mass

Mass weigh

Linear step / Angle step
max per‑substep integration limits
Linear damp / Angular damp
intrinsic velocity damping
Center of mass
local offset, editable directly
Principal inertia
shown only when mass > 0
Inertia axis
orientation of the principal inertia frame

Setting mass on a body that has a joint recomputes inertia from the collision shape's volume automatically; a body with no joint (a static root) just stores the value as entered.
