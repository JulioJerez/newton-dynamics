3URDF import

URDF joints map onto Newton joints directly: fixed → Fix6dof, continuous/revolute → Hinge (or an IK hinge, if requested), prismatic → Slider. URDF <limit> and a Newton <newton> extension element (spring/damper/regularizer, or a replaceWith override for IK variants) carry through automatically. A purely kinematic root link with no inertial data is treated as a static mount and folded away so the first real body becomes the asset root.

6Saved file format

Assets are saved as Newton's native .nd mesh format at the path chosen in Save As…. The file browser also accepts native XML assets on load. Always Save As… once for a new asset before relying on plain Save, which writes to whatever path is already associated with the open document.
