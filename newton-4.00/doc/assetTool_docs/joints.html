Joints & Colliding Pairs

Newton assets connect bodies two ways: a structural joint along the parent/child chain, and, outside that chain, editor‑defined loop joints and colliding pairs.

1Structural joints

A node with a rigid body and a parent body automatically gets a joint connecting them (default: Fix6dof, fully rigid). Change its type from the joint type dropdown in the mesh node's properties; switching types preserves the joint's current global frame so geometry doesn't jump.

Available joint types

softness, max force, max torque
Hinge

Double hinge

Spherical

Wheel

Vehicle motor / differential / tire
torque curve, friction model, slip omega

All joint types share a joint frame editor above their specific parameters: relative position and rotation, applied in the node's global frame.

2Loop joints (closed kinematic loops)

Use a loop joint to connect two bodies that aren't in a direct parent/child relationship — the second constraint that closes a loop (four‑bar linkages, gear trains, differential axles, IK effectors).

Properties Panel›Rigid body›enter loop joint
  1. Select the first body, open Rigid body, click enter loop joint.
  2. Pick the second body in the viewport or outliner.
  3. Click add loop joint. A new entry appears in the closed‑loop list under the outliner, named after both bodies.

Select the closed‑loop list in the outliner to inspect existing loop joints: pick one from the list, edit its type and parameters, or remove selected. Loop joints can be edited in the child local frame / parent local frame (relative offsets on each side) or, for most types, a single global frame control.

3Colliding pairs

By default, bodies connected by a joint don't collide with each other, but unconnected or loop‑jointed bodies otherwise do. A colliding‑pair entry is an explicit allow‑list item — add one where you specifically want two bodies to collide (e.g. two links joined only through a loop constraint).

Properties Panel›Rigid body›enter colliding pairs
  1. Select the first body, open Rigid body, click enter colliding pairs.
  2. Pick the second body.
  3. Click add pair.

Select the colliding‑pairs list in the outliner to review or remove selected pairs.

Deleting nodes cleans up references Deleting a mesh node (either variant) automatically removes any loop joint or colliding pair that referenced it, so you won't be left with dangling entries in either list.
