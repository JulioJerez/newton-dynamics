Physics Properties

The Properties Panel exposes all physics data for the currently selected node. Each section is independently collapsible.

Mesh Node

Always shown when a mesh node is selected. Controls the node's name, transform, visibility, and modifier.

FieldDescription
NameEditable text. Must be unique in the scene — the editor auto-appends _1 if a conflict is detected.
Parent space transformWhen checked, position/rotation inputs show absolute local values. When unchecked, inputs are relative increments applied on Enter.
Transform pivot onlyMoves only the node's pivot, shifting geometry and children in the opposite direction to compensate. Useful for re-centering origins.
VisibleHides the node from ray-cast selection and rendering.
Add nodeAppends a new child mesh node with a generated unique name.
Clone nodeDeep-copies the selected node and all its children. Renames clones by appending _.
Add body / Delete bodyAttaches or removes a ndMeshBodyDynamic. Adding also creates a default Fix6dof joint to the nearest parent body.

Node Transform

Two sub-sections appear: node transform (the pivot matrix) and, if geometry exists, geometry transform (the geometry sub-pivot offset).

Both support two modes set by Parent space transform:

  • On: Shows current absolute Euler angles and position. Edits set exact values.
  • Off: Shows zeros. Entering a value applies a relative delta on Enter, then resets back to zero.

Align to Target

Click align to target to enter alignment mode, then click another node in the viewport. When you click pick to target, the selected node's pivot rotates so its X-axis points toward the target. Only the pivot is moved (equivalent to Transform pivot only being on).

Modifier

Nodes without a rigid body can have a transform modifier that drives their matrix from external logic:

ModifierDescription
noneNo modifier — node is purely static.
LookAtRotates the node to face a selected target node each frame.
TwoLinksIKTwo-bone IK chain targeting another node. Requires at least one child. Configure the solution sign (±1) and which child is the mid-link.
UserDefinedStores a custom constructor string consumed by runtime code.

Rigid Body

Shown only when the selected node has an attached rigid body.

FieldDescription
massTotal mass in kg. Editing this recalculates inertia from the current collision shape.
mass weighVolume-weighting scalar used by the Normalize Mass Distribution tool. Default 1.0.
linear stepMaximum linear displacement per substep for continuous collision. Range 0.1 – 30.
angle stepMaximum angular displacement per substep in degrees. Range 10 – 180.
linear dampIntrinsic linear velocity damping, 0 – 1.
angular dampPer-axis angular velocity damping (XYZ), 0 – 1.
comLocal centre-of-mass offset from the node pivot, in local space.
principal inertiaInertia along each principal axis in kg·m². Entered as direct values (not reciprocals).
inertia axisEuler angles (degrees) of the principal inertia frame relative to the body frame.
Note on inertia: When you edit mass, inertia is automatically recalculated using the collision shape geometry. If you edit principal inertia or inertia axis directly, those values are stored as-is — useful for tuning but they will be overwritten next time you change mass.

Collision Shapes

Select the shape type from the Collision shape dropdown. Changing shape type creates a new default instance.

📦
Box

Defined by X, Y, Z half-extents. Min dimension 0.01.

⚽
Sphere

Single radius. Min 0.01.

💊
Capsule

Two radii (radius0, radius1) plus height. Min 0.01.

🔵
Cylinder

Two radii plus height. Allows tapered cylinders.

🔶
Chamfer Cylinder

Cylinder with rounded edges. Radius + height.

🔩
Wheel

Vehicle tire shape. No editable parameters in this panel.

🔷
Convex Hull

Built from mesh vertices. Tolerance and max point count are editable.

🧩
Compound

Multiple sub-shapes. Sub-shape count is read-only here.

⬜
Null

No collision. Use for kinematic markers or invisible joints.

Shape Transform

Below the shape selector, Shape Transform controls position, rotation, and scale of the shape within the body. These are stored as the shape instance's local matrix and scale vector.

Build Visual Mesh

Clicking build visual mesh regenerates the render geometry from the current collision shape. This overwrites the existing geometry on the node. Useful for keeping visual and collision meshes synchronized after you edit the shape parameters.

Structural Joints

Shown when a node has both a rigid body and a parent body. A joint constrains the degrees of freedom between parent and child.

Available joint types:

Fix6dof Hinge Slider Plane Roller Cylinder Double Hinge Wheel Spherical Motor Vehicle Tire Differential

Common joint parameters

ParameterDescription
Joint frame (rel position / rel rotation)Incremental offset applied to the joint's local frame in global space. Both parent and child frames update to stay consistent.
spring constSpring stiffness of the actuator. 0 = no spring.
damper constDamping coefficient. 0 = no damping.
regularizerConstraint softness / compliance parameter.
limits onToggle (true/false). Enables angular/linear limit enforcement.
min / max limitLimit angles in radians or linear distances. Hinge/slider min must be ≤ 0, max ≥ 0.

Wheel joint extra parameters

ParameterDescription
upper stop / lower stopSuspension travel limits (m).
steering angleMaximum steering angle in degrees, clamped 0 – 45.
brake torque / hand brake torqueBraking torques in N·m.

Loop Joints

Loop joints connect two non-parent-child bodies, forming closed kinematic loops (e.g. a gear, a four-bar linkage). They live in the loop joints container node rather than on the child body.

How to add a loop joint:
1. Select one body node.
2. Click enter loop joint in the Rigid Body section.
3. Click the second body in the viewport or outliner.
4. Click add loop joint. A Spherical joint is created by default.
5. Click exit loop joints to leave the mode.

Available loop joint types:

Fix6dof Hinge Slider Double Hinge Spherical Gear Swivel Position Effector Gear Box Differential Axle

Gear joint

A single gear ratio scalar. Positive ratios rotate in the same direction; negative ratios reverse direction.

Gear Box joint

Vehicle gear box with a full gear-ratio array (forward + reverse), crown gear ratio, idle/locked clutch torques, torque converter, and gear-shift delay in ticks.

Swivel Position Effector

IK end effector with separate linear spring/damper/regularizer/max-force for positioning and optional angular spring for swivel control. Workspace radii and rotation order (pitchRollYaw / pitchYawRoll) are also configurable.

Colliding Pairs

Pairs of bodies that are explicitly allowed to collide even though they share a joint connection. By default, bodies connected by a joint do not collide with each other.

How to add a colliding pair:
1. Select a body node.
2. Click enter colliding pairs in the Rigid Body section.
3. Click the second body.
4. Click add pair.
5. Click exit colliding pairs.

The Colliding Pairs list is visible in the Outliner as a container node. You can also remove individual pairs with remove colliding pair.

Render Materials

Shown when the node has geometry. Lists all materials on the mesh; select one from the list to edit.

FieldDescription
material nameIdentifier used for texture lookups.
ambient / diffuse / specular / reflectionRGB color vectors for PBR-style rendering.
opacity0.0 = transparent, 1.0 = fully opaque.
shinessSpecular exponent / roughness.
textureTexture filename (searched in the media path).
Note: Editing any material parameter rebuilds the visual scene. The camera position is preserved but the current selection is restored by name.

Custom Properties

Arbitrary key-value data attached to a node, consumed by game-runtime code. Three types:

TypeValue
Float propertyA single ndReal number.
String propertyAn arbitrary text string.
Node propertyA weak reference to another scene node (select via the viewport).

Use new property to add, and delete selected to remove. The property name is editable for all types.
