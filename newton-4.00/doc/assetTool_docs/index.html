Newton Asset Editor

A visual editor for building physics assets: rigid‑body hierarchies, constraint joints, collision shapes and render meshes, saved as .nd files that the Newton runtime can load directly. This guide covers the interface, the mesh and body inspector, joints, editing tools, and file operations.

Who this is for Anyone assembling or tuning a Newton asset by hand — characters, vehicles, ragdolls, mechanisms — rather than generating one purely through code or an FBX/URDF import pipeline.

01What the editor does

A Newton asset is a tree of mesh nodes. Any node can carry a render geometry, a rigid body with a collision shape, and a joint connecting it to its parent body. On top of that tree, an asset can define loop joints (constraints that close a kinematic loop outside the parent/child chain) and colliding pairs (an explicit allow‑list of bodies that are permitted to collide with each other). The editor gives you a 3D viewport, an outliner for the hierarchy, and a properties panel for whatever is currently selected.
