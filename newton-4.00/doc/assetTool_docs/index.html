Getting Started

1

Launch the editor

Run the executable. A blank mesh named root is created automatically so you can begin immediately.

2

Load a mesh

Use File → Load to open a .nd file, or File → Import fbx / Import urdf to bring in external models.

3

Select nodes

Click any node in the Outliner Panel or click geometry in the viewport. The Properties Panel updates immediately.

4

Configure physics

Add a rigid body, pick a collision shape, set mass and inertia, then define joints to connect bodies in a hierarchy.

5

Save

Use File → Save to overwrite the current .nd file or File → Save As to write a new one.
